# Crecimiento de Vehículos Eléctricos – Avance 1

Proyecto Final Integrador (Programación Avanzada), Proyecto 8.

**Pregunta orientadora:** ¿Cuál será el crecimiento esperado de los vehículos eléctricos?

## Objetivo
Analizar la evolución de ventas, stock e infraestructura de carga de vehículos
eléctricos por país y año, calcular tasas de variación y proyectar la adopción.

## Estructura
```
datos/      dataset y README con su procedencia
reportes/   informes (avance_1.pdf)
src/        funciones (carga.py)
main.py     punto de entrada
```

## Ejecución
```bash
pip install -r requirements.txt
python main.py
```
Debe ejecutarse desde la raíz del proyecto, con el dataset en `datos/`
(ver `datos/README.md`).
